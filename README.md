## Тема

Строки в C#.

## Что реализовано

- определение длины строки;
- подсчёт букв, цифр, пробелов и слов;
- поиск первого индекса символа;
- удаление пробелов по краям;
- перевод в верхний регистр;
- замена пробелов на подчёркивания.

## Короткие ответы

1. Чем отличаются `string` и `char`?

Ответ: string - это строка, которая состоит из нескольких элементов, а char - это один элемент, например буква 'a'

2. Почему вызов `text.Trim()` без сохранения результата не меняет `text`?

Ответ: Потому что строка - неизменяемый тип данных

3. Зачем при разделении строки используется `RemoveEmptyEntries`?

Ответ: RemoveEmptyEntries - исключает пустые части, возникающие из-за пробелов по краям и нескольких пробелов подряд
